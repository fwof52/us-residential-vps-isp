## 机房 IP 跑不动 TikTok，差的是 IP 身份

## 双 ISP、静态 ISP、真实家宽：三种“住宅”买前要分清

这三个词经常被混着用，实际是三样东西，对应的业务场景也不一样。

**双 ISP 家宽 IP**：一个 IP 同时归属两家美国运营商，WHOIS 里能看到两条 ISP 记录，平台识别难度最高，欺诈评分通常为 0。带宽受家宽网络限制，50–300Mbps 是常见范围，跑 TikTok、解锁 Netflix/Disney+ 这类流媒体、访问 AI 平台都够。

**静态住宅 ISP IP**：固定分配、长期不变，适合需要同一个 IP 维护账号状态的场景，比如店铺登录、长期养号。丽萨主机的双 ISP 套餐本身主打“静态独享”——IP 归你一个人用、不轮换，所以多数人不需要单独再找“静态 ISP”产品。这和按流量计费、多人轮换的住宅代理完全是两回事，后面 FAQ 里细说。

**真实家宽 IP**：服务器物理部署在美国的住宅房屋里，接的是当地运营商的家庭光纤，是目前纯净度最高的形态。丽萨主机的西雅图方案就托管在真实家庭住宅中，接入本地运营商 Atlas Networks 的光纤，官方宣传口径是 100% 模拟当地上网环境。价格也最贵，适合“IP 环境没得商量”的跨境平台注册和长期运营。

## 常见问题

**住宅 IP VPS 和住宅代理有什么区别？**
住宅代理是一批 IP 给很多人共享轮换，用的人多了纯净度会衰减；住宅 IP VPS 是独享，这个 IP 只有你在用，不存在被别人“用脏”的问题。长期业务选独享 VPS 更稳。

**一台能跑几个账号？**
精简版（1核1GB）跑 3–5 个账号没问题；要跑自动化脚本或者账号数量更多，从进阶版（2核2GB）起步更稳，不容易因为资源紧张拖累账号表现。

**IP 被平台封了怎么办？**
年付用户一年内可申请免费换 IP。住宅 IP 被封的概率比机房 IP 低不少，但不是零，业务量大的话还是要有备份方案。

**支持 Windows 吗？**
部分套餐支持，具体以套餐详情页为准；默认系统是 Linux。
